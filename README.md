# QR Checker

A Flask web application that generates QR codes from user data and displays the stored information.

## Features

- Generate QR codes from personal data (name, age, weight, height, goal)
- Display generated QR codes
- View data stored in scanned QR codes

## Installation

```bash
pip install flask qrcode
```

## Usage

Run the application:
```bash
python app.py
```

Open your browser and navigate to `http://127.0.0.1:5000`

## Tech Stack

- Flask
- qrcode library
